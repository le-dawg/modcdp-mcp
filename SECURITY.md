# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability within `modcdp-mcp`, please do **not** disclose it publicly via GitHub Issues.

Instead, please send an encrypted email or report it privately via GitHub Security Advisories. We will review and respond promptly.
